## Итоговый вывод и рекомендации

### Данные и подготовка

- Выгрузка: `afisha.purchases` + `events` + `city` + `regions`; фильтры: только `mobile/desktop`, исключены «фильм».
- Поля: `user_id`, `order_dt`, `order_ts`, `device_type_canonical`, `currency_code`, `revenue`, `tickets_count`, `days_since_prev`, `event_id`, `event_name`, `event_type_main`, `service_name`, `city_name`, `region_name`.
- Конвертация валюты: добавлен `revenue_rub` (KZT→RUB по датам, курс указан за 100 тенге, приведён к 1 тенге).
- Предобработка: типы дат/чисел, контроль аномалий; выбросы по `revenue_rub` ограничены 99‑м перцентилем. Пропуски ожидаемо только в `days_since_prev` (первая покупка).

### Ключевые показатели

- Пользователи: 21 707.
- Средняя выручка с заказа: ~545.8 ₽.
- Доли возвратов: ≥2 заказа — ~61.7%; ≥5 заказов — ~29.1%.

### Что связано с возвратом (признаки первого заказа)

- Тип мероприятия: выше возвраты у «театр», «выставки», «концерты»; ниже — «спорт», «ёлки».
- Устройство: `desktop` немного выше `mobile`.
- География: пользователи из крупных регионов возвращаются чаще (напр., Каменевский, Североярская, Широковская).
- Оператор: выше среднего у «Билеты в руки», «Весь в билетах», «Край билетов», «Дом культуры»; ниже — «Мой билет», «Билеты без проблем».

### Средняя выручка и билеты

- Вернувшиеся пользователи имеют более высокий «типичный» чек (медиана `avg_revenue_rub` выше), по среднему различия умеренные.
- Лучшая доля возвратов у сегмента `avg_tickets_count` 2–3 билета; 5+ — заметно ниже.

### Временные характеристики

- День недели первой покупки: влияние слабое (около 60–64% вокруг среднего ~61.7%); Суббота и Понедельник немного выше.
- Интервалы между заказами: у пользователей с ≥5 заказами типичный интервал короче (медиана ~7.8 дня против ~9.0 дня у группы 2–4).

### Корреляционный анализ (phi_k)

- Наибольшая (слабая) связь с числом заказов у `first_region` (~0.128) и `first_service` (~0.103).
- Временной признак `weekday_first` — слабая связь (~0.055).
- Числовые агрегаты по пользователю (`avg_revenue_rub`, `avg_tickets_count`, `avg_days_between_orders`) показывают близко к нулю на общей выборке — полезнее внутри сегментов (1; 2–4; 5+ заказов).

### Рекомендации

- Онбординг/точки входа: продвигать «театр/выставки/концерты», усиливать `desktop`‑сценарии и сильных партнёров (напр., «Билеты в руки», «Край билетов»).
- Региональный фокус: приоритизировать крупные регионы с возвратом выше среднего; запускать локальные акции с партнёрами.
- Коммуникации: таргетировать ремайндеры в окне ~7–10 дней после покупки; тестировать частоту и сегменты.
- Пакеты/бандлы: стимулировать заказы на 2–3 билета (связано с лучшим удержанием).
- Аналитика: углублять анализ внутри сегментов по `total_orders` (1; 2–4; 5+); подтверждать находки A/B‑тестами.
